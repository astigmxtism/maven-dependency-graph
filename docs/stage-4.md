# Этап 4. Обратные зависимости

Дата коммита: **07.11.2026, 22:34:00 +03:00**.

## Конфигурация

В секцию `[settings]` добавляются необязательные параметры:

```ini
reverse = true
reverse_target =
```

По умолчанию `reverse=false`. Пустая цель означает значение `package`.
При заданной цели и выключенном режиме выдаётся ошибка конфигурации.
Формат цели проверяется так же, как формат основного пакета.

## Алгоритм и область поиска

1. Инвертировать все рёбра известного графа: `A → B` становится `B → A`.
2. Вызвать **тот же `build_graph` с рекурсивным BFS** из третьего этапа.
3. Вывести найденные прямые и транзитивные обратные зависимости в порядке BFS.

Корень исключается из списка зависимых пакетов даже при наличии цикла.
При этом петли и замыкающие рёбра сохраняются в графе.
В обратном графе `X → Y` означает «Y зависит от X».

В файловом режиме поиск выполняется по **всему JSON-репозиторию**,
а не только по прямым зависимостям цели. Поэтому находятся все его
компоненты, которые зависят от выбранного пакета.

В Maven-режиме сначала собирается транзитивное замыкание `package`,
после чего выполняется поиск для `reverse_target` внутри этого графа.
Произвольный URL Maven-репозитория не предоставляет полного индекса
пакетов, поэтому глобальный поиск всех потребителей во всём Maven Central
по одному POM невозможен. Эта область поиска задана явно.

## Демонстрация

```console
py -3 run.py --config examples/reverse/diamond.ini
Обратные зависимости D:
B, C, A
В обратном графе X -> Y означает: Y зависит от X.
Порядок BFS: D, B, C, A
D -> B, C
B -> A
C -> A
A -> (нет зависимостей)
Вершин: 4; рёбер: 4

py -3 run.py --config examples/reverse/shared.ini
Обратные зависимости B:
A, C, D
В обратном графе X -> Y означает: Y зависит от X.
Порядок BFS: B, A, C, D
B -> A, C
A -> (нет зависимостей)
C -> D
D -> (нет зависимостей)
Вершин: 4; рёбер: 3
```

| INI в `examples/reverse/` | Цель | Обратные зависимости |
| --- | --- | --- |
| `chain.ini` | C | B, A |
| `diamond.ini` | D | B, C, A |
| `cycle.ini` | A | C, B |
| `shared.ini` | B | A, C, D |
| `isolated.ini` | E | Нет |
| `self-loop.ini` | A | Нет других пакетов; петля сохранена |

Пример Maven с отдельной целью:

```console
py -3 run.py --config examples/reverse/httpclient.ini
```

В графе HttpClient пакет `commons-codec:commons-codec:1.11` имеет
обратную зависимость `org.apache.httpcomponents:httpclient:4.5.14`.
На этапе 5 текстовый список заменяется визуализацией выбранного направления.
