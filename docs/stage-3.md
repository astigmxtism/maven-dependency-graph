## Рекурсивный BFS

`GraphBuilder.visit_levels` обрабатывает **весь текущий фронт**, собирает
следующий и рекурсивно вызывает себя для следующего уровня. Это BFS,
а не рекурсивный DFS. Рекурсия выполняется порциями по 64 уровня;
внешний цикл продолжает с сохранённым фронтом. Поэтому глубина графа
не ограничивается стандартным стеком Python. Проверяется цепочка
из 1500 вершин без изменения `sys.setrecursionlimit`.

Состояние посещения — пара `(пакет, накопленные exclusions)`.
Циклическое ребро сохраняется, повторное состояние не ставится в очередь.
Соседи каждого пакета запрашиваются один раз. Для обычного тестового графа
сложность — `O(V + E)`, память — `O(V + E)` с учётом сохранённого графа.
При Maven-exclusions возможны несколько состояний одной вершины.

Практические лимиты: 10 000 вершин, 100 000 состояний, JSON до 4 МиБ.
При превышении выдаётся ошибка, частичный результат не выдаётся за полный.

## Тестовый репозиторий

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
```

Все вершины должны быть явно описаны, включая листья. Имена соответствуют
`[A-Z]+`; кириллица, числа, строчные буквы, повтор ключа и неизвестная ссылка
считаются ошибкой. Повторные рёбра объединяются. Порядок объявления сохраняется.

```console
py -3 run.py --config examples/test/diamond.ini
Порядок BFS: A, B, C, D
A -> B, C
B -> D
C -> D
D -> (нет зависимостей)
Вершин: 4; рёбер: 4

py -3 run.py --config examples/test/cycle.ini
Порядок BFS: A, B, C, D
A -> B
B -> C
C -> A, D
D -> (нет зависимостей)
Вершин: 4; рёбер: 4
```

## Другие случаи

| INI в `examples/test/` | Проверяемый случай | Вершины / рёбра |
| --- | --- | --- |
| `chain.ini` | Транзитивность A → B → C | 3 / 2 |
| `diamond.ini` | Общая зависимость D; порядок BFS A, B, C, D | 4 / 4 |
| `cycle.ini` | Цикл A → B → C → A и лист D | 4 / 4 |
| `self-loop.ini` | Петля A → A и A → B | 2 / 2 |
| `disconnected.ini` | Из корня A достижимы только A и B | 2 / 1 |
| `isolated.ini` | Пакет без зависимостей | 1 / 0 |

## Maven-граф

Граф строится с точки зрения **потребителя опубликованного пакета**:
раскрываются обязательные `compile` и `runtime` зависимости.
`test`, `provided`, `system` и `optional` не входят в runtime-граф.
Полный список прямых объявлений был показан на втором этапе.

Exclusions наследуются по конкретному пути, поддерживается `*`.
Если пакет доступен другой ветвью без запрета, он сохраняется.
Граф содержит объединение допустимых рёбер; это не дерево установки.
Версии представлены отдельными GAV-вершинами: конфликты версий
не скрываются правилом Maven «ближайшая версия побеждает».
